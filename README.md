Обработка для импорта товаров из CSV-файла сайта в справочник «Номенклатура». Автоматизирует создание элементов, распределение по группам и привязку видов продукции.
Ключевые особенности:

    Оптимизация: Предварительная загрузка соответствий (ID сайта → Ссылка 1С) в коллекцию Соответствие. Исключает запросы к БД внутри цикла.
    Асинхронность: Неблокирующий выбор файла на клиенте (&НаКлиенте, Ждать).
    Надежность: Изоляция ошибок (Попытка/Исключение) — сбой на одной строке не прерывает всю загрузку.

Технологии:
Управляемые формы Асинхронные вызовы Язык запросов Работа с файлами на сервере

# Обработка загрузки видов продукции из CSV

[ЗагрузкиВидовПродукции](https://github.com/K-Kerimow/1C_Programmer_netology/blob/main/%D0%97%D0%B0%D0%B3%D1%80%D1%83%D0%B7%D0%BA%D0%B0%D0%92%D0%B8%D0%B4%D0%BE%D0%B2%D0%9F%D1%80%D0%BE%D0%B4%D1%83%D0%BA%D1%86%D0%B8%D0%B8.epf)

Обработка для импорта данных  из CSV-файла в конфигурацию. Автоматизирует создание видов и связанной с ними структуры справочников.
Функционал

    Импорт видов: Создает элементы в справочнике ВидыПродукции на основе данных из CSV.
    Автоматическое создание групп: для каждого нового вида автоматически формируются соответствующие группы в справочниках:
        Номенклатура
        КодыНеисправностей

Технические особенности

    Клиент-серверное взаимодействие: выбор файла реализован на клиенте с использованием асинхронных методов (&НаКлиенте, Ждать), что обеспечивает отзывчивость интерфейса. Основная логика обработки выполняется на сервере (&НаСервере).
    Обработка ошибок: Используется конструкция Попытка...Исключение для каждой записи. Ошибка при создании одного элемента не прерывает обработку всего файла.
    Работа с файлами: Чтение CSV осуществляется через общий модуль ЧтениеИзФайлаСервер.


# 📅 Заполнение производственного календаря 1С (isdayoff.ru)

Универсальная внешняя обработка для платформы **1С:Предприятие 8**, предназначенная для автоматического заполнения регистра сведений «Календарь» данными о рабочих и выходных днях.

[ЗаполнениеКалендаря](https://github.com/K-Kerimow/1C_Programmer_netology/blob/main/%D0%97%D0%B0%D0%BF%D0%BE%D0%BB%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5%D0%9A%D0%B0%D0%BB%D0%B5%D0%BD%D0%B4%D0%B0%D1%80%D1%8F.epf)

## 🚀 Ключевые особенности

*   **Интеграция с API:** Использует данные сервиса [isdayoff.ru](https://isdayoff.ru/), который предоставляет актуальный производственный календарь РФ (учитывает государственные праздники и официальные переносы выходных).
*   **Высокая производительность:** 
    *   Реализована **массовая запись** данных в регистр одной транзакцией (вместо построчной записи каждого дня).
    *   HTTP-соединение создается один раз и переиспользуется, что ускоряет работу при заполнении больших периодов.
*   **Отказоустойчивость:** В случае недоступности интернета или ошибок сервиса обработка автоматически переключается на расчет по стандартной **пятидневной рабочей неделе**.
*   **Гибкость:** Позволяет заполнять календарь за любой выбранный пользователем интервал дат.

## 🛠 Требования

*   Платформа 1С:Предприятие 8.3 (рекомендуемая версия не ниже 8.3.10).
*   Наличие доступа к сети Интернет с сервера 1С (для обращения к `isdayoff.ru`).
*   В конфигурации должен существовать регистр сведений с именем **`Календарь`**, содержащий следующие измерения:
    *   `День` (Тип: *Дата*)
    *   `РабочийДень` (Тип: *Число*)

### Настройки и НСИ
*   **Контрагенты:** Валидация ИНН (алгоритм контрольных сумм), автозаполнение полного наименования по ОПФ, динамическая доступность КПП.
*   **Сотрудники:** Динамические формы доступа (Администратор / Пользователь). Интеграция с пользователями ИБ: создание, смена пароля, блокировка прямо из карточки сотрудника.
*   **Номенклатура:** Иерархия товаров и услуг, ставки НДС, номенклатурные группы.
